CLI Study Dashboard 是一个轻量级的命令行效率工具。它旨在解决学习/工作开始时“不知道先干什么”以及“手动打开各种软件太繁琐”的痛点。
只需一行命令，即可查看今日待办，并一键拉起你的专属学习工作环境。
核心功能
- **今日待办**：从 tasks.json 中读取并高亮显示今日必须完成的任务。
- **一键环境启动**：根据配置自动打开常用的学习网站、本地笔记软件或代码编辑器。
- **AI 番茄钟助手**：内置一份专门用于专注学习的 AI Prompt，帮你快速进入心流状态。
